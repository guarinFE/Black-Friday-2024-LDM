# Black Friday 2024 · Loja do Mecânico

Landing page que desenvolvi para a campanha de **Black Friday 2024 da Loja do Mecânico**, a partir de um layout no Figma.

Este repositório reúne o arquivo da página como registro do trabalho de desenvolvimento front-end realizado na campanha.

## Minha participação

- Implementação do layout em HTML, CSS e JavaScript.
- Configuração de carrosséis com Tiny Slider.
- Construção de FAQ com accordions e conteúdo expansível com “Leia mais”.
- Ajustes de layout para diferentes larguras de tela.
- Uso de elementos semânticos e metadados para descrever o conteúdo da página.

O design foi fornecido pelo layout no Figma. Não são apresentados aqui números de conversão, resultados de busca ou métricas de performance.

## O que há na página

- Apresentação da campanha e conteúdo sobre Black Friday.
- Carrosséis de categorias e marcas.
- Links para páginas de produtos e categorias da Loja do Mecânico.
- Textos expansíveis e perguntas frequentes.

## Tecnologias

HTML, CSS, JavaScript, Bootstrap, jQuery e Tiny Slider.

## Estrutura

```text
online.html   # HTML, estilos e scripts da landing page
README.md     # Contexto e orientações de visualização
```

O HTML, o CSS e os scripts próprios estão no mesmo arquivo porque a página foi implementada por meio de uma plataforma interna de administração da empresa.

## Como visualizar

```sh
git clone https://github.com/guarinFE/Black-Friday-2024-LDM.git
cd Black-Friday-2024-LDM
```

Abra `online.html` no navegador. Não há etapa de instalação de pacotes nem processo de build neste repositório.

Com Python instalado, também é possível servir a pasta localmente:

```sh
python -m http.server 8000
```

Depois, acesse `http://localhost:8000/online.html`.

## Dependências e contexto histórico

As imagens, fontes, folhas de estilo e bibliotecas são carregadas de endereços externos da Loja do Mecânico. A visualização depende de conexão com a internet e da disponibilidade desses recursos.

Os links e textos pertencem à campanha de 2024. Ofertas e destinos podem ter mudado desde então. Este repositório documenta a implementação da página; não reproduz o funcionamento completo do e-commerce.
